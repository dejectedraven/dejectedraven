# duskraven

独立游戏开发者，也是游戏影像的记录者。

平时做小体量的独立游戏（偏叙事与解谜），也习惯把喜欢的游戏记录下来——
截图、录像、角色与场景的影像素材，用来剪纪念视频、给同人插画当参考。

## 独立游戏

做过几款小体量作品，自己写代码、自己画素材，题材偏叙事与解谜；
其中有的还在打磨，有的只在小范围分享过。

做游戏这件事让我对「一个世界是怎么被搭起来的」特别好奇：
模型怎么绑骨、动作怎么播、界面怎么动起来——这些好奇后来变成了下面这些记录工作。

## 正在做：停服前的纪念存档

《哈利波特：魔法觉醒》陪了我很多年，如今这款游戏已经进入生命周期末期。
想到以后再也进不去那些场景、见不到那些角色和表情，我想在它落幕之前，
给自己留一份**只属于个人的影像存档**：

- 用自己电脑上安装的客户端，回顾那些熟悉的地图、角色与表情
- 剪一支纪念视频，留给自己，也留给同样舍不得的朋友
- 写几个小工具，方便随时翻看这些画面（仅在本机使用）

这份存档**不对外提供下载，也不用于任何商业用途**；
它只是一个人的回忆整理，放在自己的硬盘里，偶尔翻出来看看。

## 技术与工具

做这些事顺手写了一些小工具：把模型导出成通用的 glTF、播放 Spine 动画、
用 three.js 做 3D 浏览和换装页面。都是个人兴趣，代码放在私有仓库里，
**不包含也不分发任何游戏资源文件**。
