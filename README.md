# Hi, I'm duskraven

做游戏资源格式的逆向与工具链，主要是《哈利波特：魔法觉醒》（HPMA，NetEase NeoX 引擎）的本地资源解析：
把客户端自带的 NXPK 资源包里的模型、贴图、音频、动画，导出成 Blender / PmxEditor / MMD 能直接用的格式。

## 在做什么

| 方向 | 内容 |
| --- | --- |
| 资源提取 | NXPK 容器解析、DDS→PNG、WEM→OGG、`.mesh`/`.gim`/`.mtg` 几何与材质还原 |
| 骨骼与蒙皮 | 190+ 关节的 bind pose 还原、GLB（glTF 2.0）导出、Blender 可直接带动 |
| 动画 | `.animation`（XML 元信息）与 `.rawanimation`（NeoX 容器）解析；`CompressionLevel=None` 档已完全解出 |
| 前端 | 纯静态的 3D 浏览 / 实时换装 / Spine 动态表情播放器（three.js + pixi-spine） |

## 一些数字（个人整理，仅供研究）

- 模型单元 7700+、贴图 5000+，导出为 GLB 后可在浏览器里直接看
- 音频 33000+ 条（含 `.bnk` 内嵌音轨）
- 动画 27000+ 条（`.animation` 文本 + `.rawanimation` 二进制）
- 动态表情 600+、头像框 350 静态 / 163 动态
